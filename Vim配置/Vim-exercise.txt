VIM 快捷键训练场：从常用到进阶
================================

使用方法
--------
1. 用 vim 打开本文件，直接在每节的“实践区”里修改。
2. 每节按大致使用频率排列；先熟悉 01～08，再练后面的内容。
3. 按键说明：Esc 是退出插入模式；Ctrl+r 表示同时按 Ctrl 和 r。
   大小写有区别：w 和 W、p 和 P、i 和 I 都是不同命令。
   冒号命令和搜索输入后需要按 Enter；其他普通模式快捷键不用 Enter。
4. 迷路了先按 Esc。用 /练习01-开始 搜索对应练习区。
   更换练习时，把编号换成 02、03……；n 可以跳到下一处匹配。
5. 文件开始被改乱时，用 u 撤销。一次 u 撤销一个修改步骤。
6. 想重新练，可先用 :w /tmp/vim-practice.txt 保存副本，之后在副本里练。
   原训练文件只有保存后才会被改动。不要对珍贵文件练 :q!。
7. 想理解组合规律，先看 23；词范围对照看 04、05；历史跳转看 13。
   新增 24 是跳转专项练习。文末速查按“规律”归纳，方便复习。

小目标：每天练 10～15 分钟，每个任务重复三次，尽量不碰鼠标和方向键。
完成后在该节的 [ ] 中用 r 把空格换成 x，记录进度。


01 [ ] 模式切换、输入、保存、退出 —— 最常用
-------------------------------------------
普通模式：移动、删除、复制等命令在这个模式执行。
插入模式：打字会写入文件，通常底部会显示 INSERT / 插入。
命令行模式：普通模式按 :，输入命令并回车。

按键：
  Esc / Ctrl+[  回到普通模式
  i             在光标前插入
  a             在光标后插入
  o             在当前行下面新建一行并输入
  O             在当前行上面新建一行并输入
  :w            保存
  :q            退出；有未保存修改时会拒绝退出
  :wq           保存并退出
  :q!           放弃未保存修改并退出（最后退出练习时再尝试）

任务：在下面三行分别补上姓名、日期、目标。
      在 goal 行下面用 o 新增一行，在 name 行上面用 O 新增一行。
      输入完成后 Esc，再用 :w 保存。先不要退出。

练习01-开始
name:
date:
goal:
练习01-结束

04 [ ] 复制、粘贴、剪切 —— 最常用
--------------------------------
  yy            复制当前整行
  3yy           复制从当前行开始的三行
  p             行内容粘到下方；字符内容粘到光标后
  P             行内容粘到上方；字符内容粘到光标前
  dd 然后 p     剪切整行后粘贴
  yw            从光标处复制到下一个词的开头（可能包括空格）
  yiw           复制光标所在的整个词，不带周围空格
  yaw           复制整个词及相关空白，通常优先带后面的空白
  ye            从光标复制到向前 e 到达的词尾，包含终点
  yge           向后复制到 ge 到达的词尾，包含两端字符
  yb            向后复制到 b 到达的词首，不包含原光标字符
  yW / yE       对应 yw / ye，但按空白分隔的 WORD 计算
  ygE / yB      对应 yge / yb，但按 WORD 计算
  yiW / yaW     复制整个 WORD / 连同相关空白
  y0 / y^ / y$  复制到行首 / 首个非空白字符 / 行尾
  yG / ygg      从当前行复制到文件末尾 / 开头，按整行复制

对照实验：每次都将光标放在下面 banana 的第 3 个字母 n 上。
  原文：red banana green（用 0 → w → 2l 定位到 banana 的第 3 个字母）
  yw   得到 "nana "   ：到下个词首前，当前词前半截不在范围内。
  ye   得到 "nana"    ：到本词尾，不带后面的空格。
  yiw  得到 "banana"  ：整个词，不受处在词内哪个字母影响。
  yaw  得到 "banana " ：整个词，再带相关空白。
  yge  得到 "d ban"   ：向后到 red 的 d，包含终点 d 和原光标 n。
  引号只是展示边界，不属于复制结果。用 :reg 0 查看，避免粘贴位置干扰。
  若光标本来在词尾，e 会到下一个词尾；ye 不一定只复制一个字符。
  若光标本来在词首，b 会到前一个词首；yb 不一定只复制当前词。
  yaw 在词后无空白时可能带前面的空白；它不是固定“只加一个后空格”。
  yw 在行末有范围特例，通常停在该行最后一个词尾，不顺带复制换行。

任务：把 COPY ME 复制两份；用 dd 和 p 把 third 挪到 first 后面。
      将光标放在 banana 里面，用 yiw 复制，在 fruit: 后粘贴。

      在 my-file.txt 中比较 yiw、yiW、yaW，理解词和 WORD 的区别。

05 [ ] 按单词移动、数字重复 —— 常用
-----------------------------------
  w / b         到下一个词开头 / 向后到词开头
  e             到词尾
  ge            到上一个词尾部
  gE            向后到前一个 WORD 的尾部
  W / B / E     按空白分隔的大块移动，标点也算块的一部分
  3w            连续执行三次 w
  dw            删除到下一个词开头；在词首时常带上后面空格
  daw           删除光标所在整个词及相关空白，仍在普通模式
  diw           删除光标所在整个词，不带周围空白，仍在普通模式
  de            删除到本词词尾
  dge / db      向后删到 ge 的词尾 / b 的词首，端点规则与 yge / yb 相同
  d2w / 2dw     删除两个词对应的范围

移动规律：w / b 找词首，e / ge 找词尾；w、e 向前，b、ge 向后。
          W / B / E / gE 是对应的 WORD 版本。
  word：默认字母、数字、下划线算一类，其他连续非空白标点算另一类。
        如 my-file.txt，w 通常依次停在 my、-、file、.、txt。
        具体受 :set iskeyword? 配置影响。
  WORD：一整块非空白内容；my-file.txt、user@example.com 各算一块。
  w / e 不等于 iw / aw：前者从当前位置走，后者按对象选整体。
  iw / aw 通常接在操作符或可视选择后；单独普通模式的 i / a 是插入命令。

任务：在第一行试 w、b、e，再用 3w。
      在第二行比较 w 与 W 对 my-file.txt 的处理。
      用 dw 删除 unnecessary，再用 u 恢复并试 de。

练习05-开始

练习05-结束


06 [ ] 替换、修改、行首行尾插入 —— 常用
--------------------------------------
  r加一个字符   替换光标处字符，例如 rX
  cw            从当前位置修改词，进入插入模式
  ciw           修改光标所在整个词，进入插入模式
  caw           修改整个词及相关空白，进入插入模式
  ce / cge      修改到向前词尾 / 向后词尾，进入插入模式
  ciW / caW     修改整个 WORD / WORD 及相关空白
  C / c$        修改从光标到行尾的内容
  I             在本行第一个非空白字符前插入
  A             在行尾追加
  R             进入连续覆盖模式，Esc 结束

注意：c 才会删除指定范围后进入插入模式；d 只删除，y 只复制。
      光标在非空白字符上时，cw 通常按 ce 处理，保留词后的空白；
      dw / yw 则通常会带词后的空白。这是组合规律中的一个重要特例。

10 [ ] 文本对象：词、引号、括号、段落 —— 常用到进阶
---------------------------------------------------
理解方法：操作符 + 范围。d 删除，c 修改，y 复制。
          i 表示内部，a 表示连同包围符或相关空白。

  diw / daw     删除整个词 / 删除词及相关空白
  ci" / ca"     修改双引号内部 / 连同双引号一起修改
  di( / da(     删除圆括号内部 / 连同圆括号一起删除
  ci[ / ci{     修改方括号内部 / 花括号内部
  vip / dip     选中段落内部 / 删除段落内部
  yi" / ya"     复制双引号内文本 / 连同双引号一起复制
  yi' / ya'     复制单引号内文本 / 连同单引号一起复制
  yi( / ya(     复制圆括号内部 / 连同圆括号；yib / yab 是对应别名
  yi[ / ya[     复制方括号内部 / 连同方括号
  yi{ / ya{     复制花括号内部 / 连同花括号；yiB / yaB 是对应别名
  yip / yap     复制段落 / 段落及相邻空行
  yis / yas     复制句子 / 句子及相关空白
  yit / yat     复制标签内文本 / 连同成对标签（例如 <p>hello</p>）

规律：i = inner（内部），a = a whole object（整体及相关边界）.:。
      对引号、括号、标签，a 带包围符；对词、句子、段落，a 带相关空白。
      i 并非去掉对象内部原有的空格：yi( 会原样保留括号内的空白。
      将 y 换成 d、c，范围含义保持一致；也可先用 vi(、va( 观察选区。
      不要把 ci( 当成改当前“词”：它选的是一整个括号内部。

任务：光标放在引号内容中，用 ci" 改成 hello（保留引号）。
      在圆括号里面分别试 di(、u、da(、u。
      用 ci[ 将数组内容改为 10, 20。选中末尾段落，观察空行界限。

13 [ ] 翻屏、调整视图、跳转历史 —— 较常用
----------------------------------------
  Ctrl+d / Ctrl+u  向下 / 向上半屏
  Ctrl+f / Ctrl+b  向下 / 向上整屏
  H / M / L        到屏幕顶部 / 中部 / 底部的行
  zz / zt / zb     把当前行放到视图中间 / 顶部 / 底部
  Ctrl+o           返回上一处跳转位置
  Ctrl+i           前进到下一处跳转位置（某些终端等同 Tab）
  :jumps           查看跳转历史；G、搜索、标记跳转等会记录，hjkl 通常不记录
  '.               跳到最后一次修改所在行的第一个非空白字符
  `.               跳到最后一次修改记录的精确行、列（反引号 + 点）
  g; / g,          沿当前文件的修改历史，到更旧 / 更新的修改位置
  2g; / 2g,        一次沿修改历史走两条记录
  :changes         查看当前文件的修改位置列表
  '' / ``          回到上一次跳转前的位置：所在行首非空白 / 精确行列
  gi               回到上次离开插入模式的位置，并直接进入插入模式
  `^               只回到上次离开插入模式的位置，保持普通模式
  { / }            向后 / 向前到段落边界（文本练习中主要由空行分隔）
  ( / )            向后 / 向前到句子边界，按 Vim 的标点和空白规则识别
  [( / ])          向后 / 向前找未匹配的左 / 右圆括号
  [{ / ]}          向后 / 向前找未匹配的左 / 右花括号
  42G / 42gg       跳到第 42 行；50% 跳到文件约 50% 处
  gj / gk          按屏幕显示行下移 / 上移，适合一长行自动折成多行的文本

历史跳转怎么选：
  想回“刚才改字的地方”：`.；只关心所在行：'.。
  想找“之前改过的几处”：g;，走过头后用 g, 返回。
  想回“刚才查资料或搜索前的位置”：Ctrl+o；再向前用 Ctrl+i。
  想在“跳转前后两个位置”切换：``，只要行位置时用 ''。
  想“回去接着输入”：gi。
  g; / g, 只移动光标，不会撤销或重做；u / Ctrl+r 才改变文本。
  修改位置列表不保证每个按键一条，邻近的修改可能合并成一个位置。
  `. 记录的是修改处，可能在修改起点附近或插入末尾，不等于固定的起点。
  分清 .（重复修改）、'. / `.（最后修改位置）、g; / g,（遍历修改位置）。
  也分清 ; / ,（重复行内查找）与 g; / g,；g 前缀改变了命令含义。

      搜索 view_target，将它用 zz 放到屏幕中间，再试 zt 和 zb。

23 [ ] 组合规律：操作符 × 移动／文本对象 —— 学会举一反三
-------------------------------------------------------
核心语法：
  [寄存器] [次数] 操作符 [次数] 移动
  [寄存器] [次数] 操作符 [次数] 文本对象
  方括号表示可省略，不是实际输入；具体命令仍有特例，见下文。

第一步：先选“做什么”。
  y 复制；d 删除；c 修改（删除后进入插入模式）。
  gu 改小写；gU 改大写；= 自动缩进；> / < 增加 / 减少缩进。

第二步：再选“多大范围”。
  移动：从当前光标出发，到移动命令的目的地；边界有包含／不包含之分。
  对象：以整个词、引号、括号等为单位；例如 iw、aw、i(、a(。
  先确定光标起点，再判断命令效果。光标在词首、词中、词尾，结果可能不同。

同一个范围，换操作符就是同一族命令：
  范围      复制      删除      修改       范围含义
  w         yw        dw        cw         向前到下个词首前；cw 有特例
  e         ye        de        ce         向前到词尾，含终点
  ge        yge       dge       cge        向后到词尾，含两端
  b         yb        db        cb         向后到词首，不含原光标字符
  iw        yiw       diw       ciw        整个词，不含周围空白
  aw        yaw       daw       caw        整个词，含相关空白
  iW        yiW       diW       ciW        整个 WORD，不含周围空白
  aW        yaW       daW       caW        整个 WORD，含相关空白
  i"        yi"       di"       ci"        双引号内部
  a"        ya"       da"       ca"        双引号及内部
  i(        yi(       di(       ci(        圆括号内部
  a(        ya(       da(       ca(        圆括号及内部
  ip        yip       dip       cip        段落内部
  ap        yap       dap       cap        段落及相邻空行
  $         y$        d$        c$         当前光标到行尾
  0         y0        d0        c0         到行首，不含原光标字符
  ^         y^        d^        c^         到首个非空白，端点按移动方向判断
  f,        yf,       df,       cf,        向右到逗号，包含逗号
  t,        yt,       dt,       ct,        向右到逗号前，保留逗号

这些组合怎么推出来：
  会 ye，就能推 de / ce；会 yi(，就能推 di( / ci( / vi(。
  会 iw，还能推 guiw / gUiw；会 ap，还能推 =ap / >ap。
  在复杂范围上先用 v 加移动，或 vi( / va( 预览选区，再 y / d / c。

第三步：按需要加次数、寄存器。
  3w              移动三次 w
  d2w / 2dw       对应两次 w 的范围
  2d3w            次数相乘，对应六次 w 的范围
  y2aw            复制两个词及相关空白；iw 的计数还会计入词间空白
  "ayiw           将整个词复制到寄存器 a，随后 "ap 取出
  "_diw           删除整个词并丢到黑洞寄存器，保留原来准备粘贴的内容
  yy / dd / cc    重复操作符表示整行：复制行 / 删除行 / 修改行
  3yy / 3dd       作用于当前行起的三行

边界规律与常见特例：
  e / ge 是包含终点的移动，因此 ye / yge 包含目标词尾字符。
  w / b 是不包含远端范围边界的移动：向前 yw 不含目标词首；
  向后 yb 包含目标词首，却不含原光标字符，详见 04 的实验。
  非空白字符上的 cw 按 ce 处理，不能机械照搬 dw 的范围。
  w 配合操作符在行末有特例，通常结束于该行词尾；见 :help word。
  跨行移动还可能按整行处理，见 :help exclusive-linewise。
  g 不是统一的“反方向”开关：ge 是向后词尾，gg 是文件开头，gU 是大写。
  大写也不是统一规律：w/W 是词/WORD，i/I 是插入位置，p/P 是粘贴方向。
  不是所有跳转都能接操作符：g; / g, 属于历史导航，不能照推成 yg;。
  本节解释默认 Vim 行为，自定义映射可能改变效果。

任务：

  2. 在对应副本行的相同位置试 de、diw、daw，每次 u 恢复。
  3. 用 ciw 把 banana 改成 pear，再 Esc；观察 c 与 d 的模式差别。
  4. 光标放到引号或括号里面，比较 yi" / ya"、yi( / ya(。
  5. 从 alpha 首字母开始比较 yf, / yt,，然后比较 df, / dt,，删除后 u。
  6. 在 my-file.txt 里面比较 yiw / yiW；在最后一行用 gUiw，再 u。

常用组合速查：按规律记，不逐个死背
================================
操作：y 复制；d 删除；c 删除后输入；gu / gU 改小写 / 大写。
方向：w / b 前后找词首，e / ge 前后找词尾；W / B / E / gE 按 WORD。
范围：移动从当前位置出发；iw / aw 选整个词，iW / aW 选整个 WORD。
边界：i 取内部，a 带边界或相关空白；引号、括号、段落都可组合。
推导：ye/de/ce；yge/dge/cge；yiw/diw/ciw；yaw/daw/caw；yi(/di(/ci(。
整行：yy / dd / cc；次数：3yy、d2w、2d3w（两边次数相乘）。
精确查找：f/F 到字符，t/T 到字符前后；;/, 同向 / 反向重复查找。
重复：. 重复修改；n/N 重复搜索；@@ 重复宏。
回修改处：'. 回所在行首非空白，`. 回精确位置；g;/g, 遍历修改位置。
回跳转处：Ctrl+o/Ctrl+i 遍历跳转历史；''/`` 回上次跳转前的行 / 精确位置。
继续输入：gi 回上次插入结束处并输入；`^ 只移动。
标记：ma 设置；'a 回该行首非空白；`a 回精确位置；大写标记可跨文件。
结构：% 配对括号；[( / [{ 找包围自己的左括号；{/} 前后段落。
视图：Ctrl+d/u 半屏；zz/zt/zb 调整当前行位置；gj/gk 按显示行移动。
检查：:reg 0 看复制结果；:changes 看修改位置；:jumps 看跳转历史。
特例：非空白上的 cw 按 ce；yw/dw 在行末有特殊规则；g 不统一表示反向。
帮助：Esc → :help 命令名；边界查 :help word、:help exclusive。

核对依据：本机 Vim 帮助 motion.txt、change.txt、insert.txt。
